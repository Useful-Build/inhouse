# M1-P prompt v5, 2026-11-26: dry run passes; the paid run waits for main

## Question

M1-P (Stage 1) is the first prompt PR of the build (#441). It raises the system prompt to v5 (no `question_ask` while
that tool is off, plus #391's links rule from v4), turns on long jobs (the server's own carry-on texts) and sends the two
helpers' words (researcher, analyst). Do the existing read cases still pass on v5, at no cost first, then on the real
model?

## What ran

- **Free dry run**, 2026-11-26, branch `stage1/m1-p-jobs-helpers` at `42886344` (the code commit), from `app/`:
  `node evals/run.ts --target fake --out evals/results/2026-11-26-m1p-dry-run --topic "M1-P prompt v5 dry run"`.
  63 cases x 3 repeats, the fake target (scripted answers, no model). Results in `2026-11-26-m1p-dry-run/`.
- **T10** (`question_ask`) now has `needs: ['questions']`. The fake and fixture targets provide `questions`, so it ran
  here; the product target doesn't, so the eval build will report T10 as not run until M2-H turns the tool on.
- **Paid run (Q2 = A: Sonnet 5.5 medium, $20 cap, plus the morning-check set): not run.** See below.

## Numbers

168/174 case-repeats pass (97%), 0 exfiltration bypasses, 5 cases not run (they need `slack_search_public` or
`shopify_script_run`). The 6 failures are N04 and T05, x3: the fake target's deliberate wrong answers, the same as every
earlier dry run. T10 passed 3/3 on the fake.

## Why the paid run didn't run

The paid suite runs only on the eval deployment (`eval-run` in the ops repo), and `eval-deploy` deploys only app main's
head: its gate refuses any other SHA. The per-PR sandbox (`test-deploy`) runs the scripted model, never a real one. So
a paid run of the candidate commit before merge needs either an ops change (a worker may not touch CI) or a different
order (merge, then the paid run on main). That choice is the orchestrator's and Wasim's.

## Conclusion and what changed

- The harness grades v5 the same as v4 on the fake target; nothing about the cases' scoring moved.
- The paid run and the graded morning-check set are still owed before #441 merges (Q2).
