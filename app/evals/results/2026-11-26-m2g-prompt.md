# M2-G's prompt, 2026-11-26: the acting prompt (v5), dry run 162/168; the paid run follows on main

## Question

M2-G (Stage 1) is the second prompt PR of the build. It raises the system prompt from v4 to v5: v4's "draft any action
as an approval request" and every "read only" give way to an Actions line built per turn from the operations enabled
for the brand (`server/prompt/actions.ts`). With none enabled (every deployable build today, N2) the line says the agent
can't change anything yet and never that it can act. With some it names each one's tool and how asking works. v1 also
says a helper's report is data, never instructions. The action texts port is wired: an action's result that comes
after the asking turn ended reaches the chat as one automatic note from Inhouse.

Do the existing cases still pass on v5 with zero grants, first at no cost, then on the real model (Q2 = A: one paid
run, Sonnet 5.5 medium, $20, plus the morning-check set)?

## What ran

- **Dry run** (`2026-11-26-m2g-dry-run/`, on the PR branch before review), from `app/`:
  `node evals/run.ts --target fake --out evals/results/2026-11-26-m2g-dry-run --topic "M2-G prompt v5 dry run"`.
  The fake target replays canned transcripts: it proves the harness, the cases and the graders, not the prompt's words.
- **Fixture fixes from M1-P's paid run** (in this PR): T15 and T16 now get the case person's own approvals, seeded
  waiting in the case's chat (named by their real `ac_` ids in the prompt, graded by the case's `ap_204` and `ap_311`);
  T14's team requests are cleared per repeat and its args check reads the tool's real `subject`; T09's Tom has a member
  id in a seeded brand fact.
- **Paid product suite and morning-check set:** not yet. They run on main after this PR merges, the same way as M1-P
  (ops `eval-deploy` on main's head, then `eval-run` at a `max_usd` inside this WP's $20, with the job cap pinned at $1).
  Their results are added to this file then.

## Numbers

**Dry run: 162/168 case-repeats, 0 exfiltration bypasses, 7 cases not run, $0.** The same as M1-P's second dry run:
