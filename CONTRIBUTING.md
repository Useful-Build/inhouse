# Contributing

Thanks for looking. Inhouse is public as a case study, under [PolyForm Strict 1.0.0](LICENSE).

## Issues are welcome

Open an issue for a bug, a question or an idea. For a bug, say what you did, what you expected and what happened, with
the page, the screen size and light or dark mode. A screenshot helps.

## Pull requests from outside aren't accepted

The license doesn't grant the right to change or redistribute the code, so outside pull requests are closed without
review. Every change here is built by the maintainers' agents through the gated flow in
[docs/how-we-build.md](docs/how-we-build.md). If you have a fix in mind, describe it in an issue.

## Security issues

Don't open a public issue. Report it privately through GitHub: the repository's **Security** tab, then **Report a
vulnerability**. Private vulnerability reporting is on. See [SECURITY.md](SECURITY.md).
