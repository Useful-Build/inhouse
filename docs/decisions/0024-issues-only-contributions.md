# 0024. Issues welcome, outside PRs not accepted

- Status: accepted, 2026-11-19
- Was: production plan PD10
- Plan: [production plan, Decisions](../plans/2026-11-19-production.md#decisions)

## Context

The repo is public as a case study under PolyForm Strict 1.0.0, which grants no right to modify or distribute.

## Decision

Outside contributions are issues only. [CONTRIBUTING.md](../../CONTRIBUTING.md) says so.

## Consequences

Every change still lands through the same agent-built, gated flow. A reader can report a bug or ask a question, and
security reports go private.
